# Road Damage AI

แอป Flutter สำหรับสำรวจความเสียหายผิวถนนด้วย AI Vision — ถ่ายภาพถนน ให้ AI ระบุประเภทความเสียหาย ระดับความรุนแรง และตำแหน่งในภาพ แล้วบันทึกพร้อมพิกัด GPS เพื่อดูบนแผนที่ สรุปเป็นสถิติ และส่งออกเป็นรายงาน

โครงงานนี้ต่อยอดจากแอปตัวอย่างตรวจโรคใบพีช (GPT Vision Leaf Detect) โดยใช้โครงสร้างเดิม "ถ่ายภาพ → ส่งให้ AI วิเคราะห์ → นำผลไปใช้ต่อ" กับปัญหาถนนชำรุด

## ฟีเจอร์

- **ตรวจหลายจุดในภาพเดียว** — AI คืนความเสียหายได้สูงสุด 5 จุดต่อภาพ วาดกรอบสีตามระดับความรุนแรงพร้อมเลขกำกับ
- **แนวทางซ่อม** — ขอคำแนะนำการซ่อมบำรุง 3 ข้อจาก AI
- **บันทึกพร้อมพิกัด GPS** — เก็บผลตรวจ รูปภาพ และตำแหน่งไว้ในเครื่อง
- **แผนที่ในแอป** — ปักหมุดทุกจุดบน OpenStreetMap สีหมุดตามความรุนแรง แตะเพื่อดูรายละเอียดและนำทางด้วย Google Maps
- **Dashboard** — จำนวนภาพ จำนวนจุดเสียหาย กราฟตามระดับความรุนแรงและประเภท
- **ส่งออกรายงาน** — CSV (เปิดด้วย Excel) และ PDF

ประเภทความเสียหายที่รองรับ: หลุมบ่อ, รอยแตกลายจระเข้, รอยแตกตามยาว, รอยแตกตามขวาง, ผิวทางหลุดร่อน, ร่องล้อ, ผิวทางทรุดตัว, ฝาท่อ/ฝาบ่อชำรุด, เส้นจราจรเลือนราง, ไหล่ทางชำรุด

## การติดตั้ง

ต้องมี Flutter 3.22 ขึ้นไป (Dart 3.4)

```bash
git clone <repo-url>
cd <repo-folder>
flutter pub get
```

### ตั้งค่า API Key

แอปเรียก API รูปแบบ Chat Completions ที่รองรับภาพ (ค่าเริ่มต้นคือบริการ GenAI ของมหาวิทยาลัยขอนแก่น) ไฟล์ที่เก็บ key ไม่ได้อยู่ใน repo ต้องสร้างเอง:

```bash
cp lib/constants/api_constants.example.dart lib/constants/api_constants.dart
```

แล้วแก้ค่า `API_KEY` (และ `BASE_URL` ถ้าใช้ผู้ให้บริการอื่น) ใน `lib/constants/api_constants.dart`

### รัน

```bash
flutter run
```

การถ่ายภาพและพิกัด GPS ต้องใช้อุปกรณ์ Android/iOS หรือ emulator ที่ตั้งค่ากล้องและตำแหน่งไว้ บนเว็บใช้งานได้แต่ไม่เก็บรูปภาพในประวัติ

## โครงสร้างโค้ด

```
lib/
├── main.dart
├── constants/
│   ├── constants.dart              สีและระดับความรุนแรง
│   └── api_constants.example.dart  ต้นแบบไฟล์ API key
├── screens/
│   ├── main_shell.dart             แถบเมนูล่าง 4 แท็บ
│   ├── homepage.dart               หน้าตรวจ วาดกรอบ บันทึก
│   ├── history_page.dart           หน้าประวัติและส่งออก
│   ├── map_page.dart               หน้าแผนที่
│   └── dashboard_page.dart         หน้าสรุปสถิติ
└── services/
    ├── api_service.dart            prompt และการเรียก AI
    ├── history_storage.dart        โครงสร้างข้อมูลและการบันทึก
    ├── export_service.dart         ส่งออก CSV / PDF
    └── map_launcher.dart           เปิดแอปแผนที่ภายนอก
```

## แพ็กเกจหลัก

| แพ็กเกจ | ใช้ทำอะไร |
|---|---|
| `image_picker` | ถ่ายภาพและเลือกภาพ |
| `dio` | เรียก API |
| `geolocator` | อ่านพิกัด GPS |
| `shared_preferences`, `path_provider` | เก็บประวัติและรูปในเครื่อง |
| `flutter_map`, `latlong2` | แผนที่ OpenStreetMap |
| `fl_chart` | กราฟ |
| `pdf`, `printing`, `share_plus` | สร้างและแชร์ไฟล์รายงาน |
| `url_launcher` | เปิด Google Maps |

## ข้อจำกัด

- ผลวิเคราะห์มาจากโมเดลภาษาทั่วไป ไม่ใช่โมเดลที่ฝึกเฉพาะงานถนน ประเภทและกรอบตำแหน่งเป็นค่าประมาณ

- ข้อมูลเก็บในเครื่องของผู้ใช้ ยังไม่ซิงก์ระหว่างอุปกรณ์
